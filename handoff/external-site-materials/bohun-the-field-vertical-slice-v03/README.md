# BOHUN / THE FIELD v0.3

A rebuilt vertical slice proving a denser Ukraine-centred RTS commercial field.

## What changed
- Ukraine is now the territory of the map, not a symbolic node.
- Simplified country outline, Crimea included in the internationally recognised Ukrainian outline, Black Sea, Dnipro, roads, settlements, forest and industrial density.
- Europe is spatially continuous with Ukraine.
- Bohun is an active HQ.
- New gameplay loop: SELECT → RESEARCH → REVEAL → DISPATCH → CONNECT → FILE.
- Minimap, selected-object panel, command bar and field objective.
- I NEED / I HAVE change the operational lens of the same field.
- Presentation Mode remains usable without free camera; Explore The Field unlocks pan/zoom.

## Run
Open through any local static server, for example:

`python3 -m http.server 8080`

Then open `http://localhost:8080`.

## Scenario
1. Select PROPULSION.
2. RESEARCH SIGNAL.
3. Select revealed SUPPLIER.
4. DISPATCH LIAISON.
5. CREATE ROUTE.
6. Open PROPULSION file / capability CTA.

No combat, points, scores, fake buyer activity or public RFQ detail is included.
