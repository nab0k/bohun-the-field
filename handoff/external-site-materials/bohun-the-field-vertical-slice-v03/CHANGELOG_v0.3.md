# CHANGELOG — v0.3

## Rebuilt rather than patched
v0.3 replaces the abstract node-field composition used by v0.2.

## Spatial system
- Added a recognisable stylised Ukraine landmass as the primary map territory.
- Added adjacent Europe, Black Sea, Dnipro, roads, settlements, forests and regional labels.
- Reframed international access as physical corridors instead of an INTERNATIONAL node.
- Bohun HQ is a built environment/object with communications activity.

## Gameplay
- Added SELECT.
- Added RESEARCH SIGNAL.
- Research REVEALS a previously hidden supplier.
- Added DISPATCH LIAISON with a moving unit from Bohun HQ.
- Added CREATE ROUTE.
- Established route persists in world and minimap.
- Added field objective progression.

## UI
- Added RTS-style minimap.
- Added selected-object panel.
- Added context command bar.
- Added operational mode HUD.
- Added I NEED / I HAVE as world lenses.
- Added Explore The Field free-camera mode.

## Guardrails retained
- Current Interest remains category-level.
- Supplier/buyer are generic prototype actors.
- No buyer mandate, procurement notice, controlled-goods transaction or completed deal is implied.
- Dossier remains semantic HTML.
