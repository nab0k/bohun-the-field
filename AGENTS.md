# Codex Resource Efficiency Policy

1. Work strictly within the current task. Do not automatically proceed to the next project stage.
2. Minimize repository reading and avoid rereading code already examined when targeted search is sufficient.
3. Do not conduct broad internet research without separate permission.
4. Reuse the existing architecture and make the smallest correct changes.
5. Run targeted tests instead of the full suite when doing so is safe.
6. Do not repeat successfully completed expensive operations.
7. Stop and request a decision when scope expands materially, work is blocked, or a schema migration is required.
8. After completing a stage, save a short checkpoint for the next session using the existing checkpoint mechanism.
9. Report concisely: outcome, verification, and problems.
10. Never save resources at the expense of safety, evidence verification, secret protection, or data integrity.

## Operating mode

- One task per run.
- No unsolicited improvements.
- No broad refactoring.
- Do not call paid APIs without an agreed spending limit.
- Do not change production without permission.
- If work becomes unexpectedly complex, stop, briefly explain why, and propose a decomposition.
