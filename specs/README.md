## Что эти задания меняют против нынешнего состояния

1. Источник принимается правилом, а не отдельным разрешением владельца на каждое подключение (A2SA). Без этого цепочка A не станет автономной.
2. Компании ищутся массово по спискам (B1CD), а не только в новостях.
3. Карточка заполняется по плану источников для каждого из 10 разделов (B4CE), а не одной страницей сайта.
4. Одна проверка перед показом для всего, включая карточки (C7CR), вместо двух разных.
5. Все обращения к владельцу идут через одно место (D4OD), пачками.
6. Покрытие мира измеряется (D3QM) и само направляет поиск.
7. Оборонка определяется по методике владельца: уровни L0–L5, доказанный реестр и широкий контур (версия 2).
8. Вместо одобрения владельца — периодическая независимая проверка сторонней моделью с отчётом (D5IA, версия 2).
9. Источник — не только лента сайта: Telegram, соцсети, упоминания; способов сбора несколько (версия 2).
10. Опубликованное не снимается, а получает пометку об обновлении (версия 2).

## Решения владельца 13.11 (ответ A03)

| № | Вопрос | Ответ владельца | Где учтено |

| 1 | Принимать источник по правилам, без одобрения | Да; нужна периодическая независимая проверка сторонней моделью с читаемым отчётом | A2SA, D5IA |

| 3 | Исключённые страны | Исключений нет; по РФ, Китаю, Беларуси пока нет целевого поиска, попавшее само обрабатывается | 00_COMMON §2, B5CC |
| 4 | Эталонная компания | Делаем; какая — не названа. Предложение AI: Hensoldt | B4CE |
| 5 | Inoreader | Один из способов, только для RSS; главный — наш список | A3SL, A4SC |
| 6 | Числа-пороги | Владельцу непонятно → объяснено; стартовые значения ставит ИИ, владелец задавать не обязан | 00_COMMON, шапка и §10 |
