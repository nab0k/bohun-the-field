# Native GLiNER capability diagnostic

Unmerged manual trial candidate, not a production pipeline.

Pinned GLiNER2 2.1.0 / fastino/gliner2.5-multi-v1. Twelve frozen public-source
news texts, independent native entity/relation/classification long APIs,
39 calls maximum including 3 sanity controls. No principal-event selection,
event identity, text generation or model API charges.

Gold stays on the owner's Mac. Input text is delivered in a temporary secret;
results return encrypted to the owner's existing public certificate.
Workflow requires owner-only same-repository PR, pinned head/bundle/packet,
one new label, expiry and no previous trial attempt. No schedule or merge.

Outputs are unevaluated diagnostic evidence, never automatic public content.
