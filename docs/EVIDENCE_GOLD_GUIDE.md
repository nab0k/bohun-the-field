# Эталонная разметка для Evidence Phase 1 (инструкция для разметчика)

Цель: получить 20–30 реальных англоязычных статей с ручной разметкой, чтобы впервые измерить precision, recall, модальность и атрибуцию на настоящих текстах. Разметку делает **человек**: если размечает LLM, она оценивает саму себя.

## Что размечать в каждой статье

Каждое **существенное утверждение** о мировой оборонной и dual-use индустрии: контракт, присуждение, поставка, финансирование, партнёрство, производство, испытание, политика, отмена, отказ. Фон, мнения журналиста и общеизвестные описания систем не размечаются или помечаются `essential: false`.

| Поле | Правило |
|---|---|
| `evidence_text` | Минимальный **дословный** непрерывный фрагмент, из которого следует утверждение. Копировать из сохранённого текста без правок, включая странные пробелы («Camden , Arkansas»). Если фрагмент встречается в тексте дважды, расширить его до уникального. |
| `claim` | Одна фраза своими словами, без новых фактов. Подлежащее назвать полностью («PAC-3 Edge», а не «it»). |
| `modality` | `occurred` — источник утверждает, что произошло; `announced` — актор заявляет о себе (пресс-релиз, «the company said it won»); `planned` — план, намерение, прогноз, «will», «expected», «would»; `negated` — источник утверждает, что не произошло, или отрицает; `cancelled` — было решено, затем отменено; `speculative` — «may», «reportedly», неподтверждённые сведения; `unknown`. **Оговорку из придаточного не терять:** «a new interceptor that would represent…» → `planned`, а не `occurred`. |
| `asserted_by` | Кто утверждает, **полным именем организации или человека**: «Valdorian Ministry of Defence», а не «the ministry». Издание указывать, только если оно само источник сведений («according to Harbour Defence Weekly»). Если автор утверждения — само издание, `null`. |
| `event_date` | Дата события, только если она есть в тексте, с годом. «October 9» без года — `null` с пометкой `year_missing: true`. Дату публикации не использовать. |
| `essential` | `true`, если без этого утверждения карточка события была бы неполной. |

## Процесс

1. Разметчик A размечает все статьи; разметчик B независимо размечает 20 % из них.
2. Согласие по модальности считается как Cohen's κ, по наличию утверждения — как совпадение фрагментов (IoU ≥ 0,5). При κ < 0,6 сначала уточняется эта инструкция, и только потом считаются метрики систем.
3. Разметка делается **до** запуска экстракторов на этих статьях и не правится по их результатам.

## Формат хранения (репозиторий публичный)

Для чужих статей текст в репозиторий не попадает. Пункт разметки хранится как `char_start`, `char_end`, `span_sha256` (SHA-256 фрагмента сохранённой версии текста) плюс поля из таблицы. `metrics.score_against_gold` проверяет хеш и останавливается при несовпадении. Шаблон: `intelligence/fixtures/evidence_phase1/gold-template.json`.

Где хранить разметку с цитатами до перевода в офсеты, решает владелец. Варианты: приватный репозиторий, страница Notion или новая таблица в `bohun_staging` (это изменение схемы, нужно отдельное разрешение).

## Размер выборки

20–30 статей примерно по 5–10 существенных утверждений дают 100–300 утверждений. Этого достаточно, чтобы отличить recall 0,7 от 0,9, но мало для оценки доли редких ошибок (отмена, отрицание). Для них нужны целенаправленно подобранные статьи.
