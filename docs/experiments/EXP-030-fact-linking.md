# EXP-030 – Fact linking (C2‑03)

**Дата:** 2026‑11‑05

**Цель:** связать факты из `atlas/undersea.json` с существующими компаниями и сохранить связь в таблице `company_facts`.

### Шаги реализации
1. Добавлена таблица `company_facts` в `store.py` и метод `add_fact_link`.
2. Реализован модуль `collectors/companies/fact_linker.py`:
   - `load_facts()` читает `atlas/undersea.json`.
   - `match_fact()` ищет точное совпадение имени (нормализованное) и страну; при неудаче – простое fuzzy‑соответствие.
   - `link_facts(store)` проходит по всем фактам, сохраняет связь `store.add_fact_link`.
3. Добавлен скрипт `scripts/run_fact_linker_test.py` – проверка без внешних зависимостей.
4. Обновлена `collectors/companies/README.md` (раздел *Fact linking*).

### Критерий успеха
- Скрипт `run_fact_linker_test.py` завершает работу без ошибок (проверено).
- В базе `company_facts` присутствует как минимум одна запись (проверено в тесте).
- Повторный запуск не создаёт дубликатов (idempotent).

### Результаты
- Все проверки прошли: `All fact linking checks passed.`
- Количество записей в `company_facts` после первого запуска: **> 0**.
- Дублирование отсутствует.
