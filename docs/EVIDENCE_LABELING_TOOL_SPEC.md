# Задание для Codex: инструмент разметки контрольного набора

Исполнитель: Codex (решение владельца 13.10.2026). Это ТЗ, а не реализация. Ограничения владельца: без новой инфраструктуры, без изменения схемы Supabase и без загрузки новых оригиналов в Supabase.

## Вход
- `docs/evidence-phase1-results/controlset-v2-labeling-sheet.csv` — 24 материала: ссылка, заголовок, издание.
- Правила разметки — `docs/EVIDENCE_GOLD_GUIDE.md`.

## Что должен делать инструмент (минимум)
1. Показать разметчику материал по ссылке. Текст читается на сайте издателя, в репозиторий не сохраняется.
2. Для каждого утверждения принять: дословную цитату, формулировку, модальность, `asserted_by`, дату события, `essential`.
3. Для каждого материала принять поля листа: доступна ли страница, язык, по теме ли, число существенных утверждений. Материал не по теме или с пустой разметкой — тоже результат: это отрицательный пример.
4. Сохранять разметку **вне публичного репозитория** (место выбирает владелец, см. GOLD_GUIDE). Цитаты — чужой текст.
5. Экспорт в формат `gold-template.json`. Офсеты и `span_sha256` вычисляются **позже**, когда будет разрешено сохранить версию текста; до этого храним цитату.
6. Второй разметчик видит те же материалы без разметки первого (слепая двойная разметка 20 %).

## Чего не делать
- Не показывать разметчику выход экстракторов: это смещает разметку.
- Не вызывать LLM и не размечать автоматически.
- Не писать в Supabase и не менять схему.

## Приёмка
- Две разметки одного материала экспортируются раздельно.
- Экспорт проходит `metrics.score_against_gold` после того, как цитаты выровнены по сохранённому тексту.
